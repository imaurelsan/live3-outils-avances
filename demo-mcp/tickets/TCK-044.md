# TCK-044 — Rapport régional

**Ouvert le** : 2026-09-17
**Priorité** : basse

## Description

La direction veut, par région, le montant total remboursable après correction
de TCK-042.

Écris `rapports/TCK-044.md` avec un tableau à trois colonnes : région, nombre
de commandes, total remboursable en euros. Trié par total décroissant.

Les régions sont dans `clients.region`. Il faut donc joindre trois tables et
appliquer le code de `remboursement.py` à chaque ligne.
