# TCK-042 — Remboursements à 0 €

**Ouvert le** : 2026-09-16
**Priorité** : haute
**Signalé par** : support niveau 2

## Description

Plusieurs clients nous remontent un remboursement calculé à **0,00 €** alors
qu'ils y ont droit. Le support a ouvert un incident pour chacun, tous avec le
même motif : `remboursement a zero`.

Nous n'avons **pas** la liste dans ce ticket. Elle est dans la base support,
table `incidents`.

## Ce qu'on attend

1. Identifie les commandes concernées **depuis la base**, pas en devinant.
2. Trouve la cause dans `remboursement.py`.
3. Corrige. `REGLES.md` fait autorité.
4. Écris `rapports/TCK-042.md` avec :
   - le nombre de commandes concernées
   - la liste de leurs identifiants, par ordre croissant
   - le total remboursé **après** correction, en euros
   - la cause en une phrase
5. Commit sur une branche `fix/TCK-042`.

## Pourquoi ce ticket

Il ne se résout pas avec une seule source. Le ticket dit *quoi*, la base dit
*qui*, le code dit *pourquoi*. C'est exactement ce que l'enchaînement de MCPs
sert à faire.
