# TCK-043 — Frais de dossier sur les commandes annulées

**Ouvert le** : 2026-09-17
**Priorité** : basse

## Description

Un client en région PACA affirme qu'on lui a retenu 2,50 € de frais sur une
commande **annulée**. `REGLES.md` dit que les annulations et les pertes ne
supportent aucun frais de dossier.

Vérifie dans le code si le cas peut se produire. Si oui, corrige et ajoute un
test. Si non, réponds dans `rapports/TCK-043.md` en expliquant pourquoi, avec
la ligne de code qui le garantit.

> Un ticket dont la réponse est « ce bug n'existe pas » est un ticket réussi.
> Encore faut-il le démontrer plutôt que l'affirmer.
